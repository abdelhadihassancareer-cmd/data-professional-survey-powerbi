# Data Professional Survey — Power BI Dashboard

## Project Overview

This project analyzes a survey of data professionals using Microsoft Power BI. The dashboard summarizes respondent demographics, salary, job roles, programming languages, career transitions, and job satisfaction.

## Dashboard

The final Power BI report is presented as a single-page interactive dashboard.

### Key KPIs

- **Total Survey Takers:** 630
- **Average Age:** 29.87
- **Average Salary:** approximately $53.9K
- **Career Change to Data:** 59.0%
- **Happiness With Salary:** 4.27 / 10
- **Happiness With Work/Life Balance:** 5.74 / 10

### Main Visuals

- Survey Takers by Country
- Average Salary by Job Title
- Favorite Programming Language
- Difficulty to Break Into Data
- Happiness With Salary
- Happiness With Work/Life Balance
- Career Change to Data

## Tools Used

- Microsoft Power BI Desktop
- DAX
- Power Query
- Microsoft Excel
- GitHub

## Dataset

The project uses the Data Professional Survey dataset. The source data was used to build the Power BI model and dashboard.

## Key Insights

- A substantial share of respondents reported switching careers into data.
- Data Scientist and Data Engineer roles rank among the higher-paying job categories in the dashboard.
- Python is the most commonly selected favorite programming language among respondents.
- Work/life balance has a higher average satisfaction score than salary in the survey.
- The United States represents the largest country group in the displayed survey breakdown.
